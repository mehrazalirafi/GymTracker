# GymTracker

A personal gym tracking app built with React Native and Expo.

## Features
- Weight tracking with trend graph
- Step tracking with trend graph
- Workout program creation and session logging
- Dashboard showing latest stats

## Stack
- React Native / Expo
- TypeScript
- AsyncStorage
- react-native-gifted-charts

## Running the project
1. npm install
2. $env:EXPO_ROUTER_DISABLE_RN_NAVIGATION_CHECK=1; npx expo start
3. Scan QR code with Expo Go on iPhone
